# Data Cleaning (Python)

### Overview

I used Python, ```numpy``` and ```pandas``` for data cleaning tasks. For this datase, I cleaned the data by removing any NULL, NA or 0 values, filtering values above or below 50% of the first price, deleting values higher than £100 and lower than £0.1, dropping columns, organizing columns by renaming and ordering them.
